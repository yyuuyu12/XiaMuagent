## 核心认知：两个维度，不要混淆

本项目有两个独立维度，必须分开理解：

### 维度一：页面样式（谁的布局？）

| | 手机版 | 桌面版（云端 + exe 共用） |
|---|---|---|
| **文件** | `backend/public/index.html` | `backend/public/desktop.html` |
| **布局** | 单栏，max-width 480px | 双栏，viewport 1280px |
| **改动后同步** | git push 即可 | git push（云端）+ cp + 打包（exe） |

> ✅ 云端桌面版和 exe 桌面版**页面完全一样**，都用 desktop.html

---

### 维度二：服务层（谁的后端？）

| | 手机版 + 云端桌面版 | exe 桌面版 |
|---|---|---|
| **服务** | ☁️ Zeabur 云端（共用） | 💻 本地 FastAPI 9101 |
| **AI 文案** | Zeabur → DeepSeek | Zeabur → DeepSeek（透传） |
| **TTS/ASR** | frp穿透 → 本地 8765/8766 | 直连 → 本地 8765/8766 |
| **数字人** | frp穿透 → 本地 7861 | 直连 → 本地 7861 |
| **frp** | ✅ 必须跑 | ❌ 不需要 |

> ✅ 手机版和云端桌面版**服务完全一样**，只是页面布局不同

## 文件边界

| 要改什么 | 改哪里 | 生效方式 |
|---|---|---|
| 手机版 UI | `backend/public/index.html` | git push → Zeabur 自动部署 |
| 桌面版 UI（云端） | `backend/public/desktop.html` | git push → Zeabur 自动部署 |
| 桌面版 UI（exe） | ↑ 同上，改完再 cp + 重新打包 | 打包后替换买家的 exe |
| 云端后端 API | `backend/routes/*.js` | git push → Zeabur 自动部署 |
| exe 本地后端 | `XiaMuDesktop/backend_local/main.py` | 重新打包 exe |

> ⚠️ 不要直接改 `XiaMuDesktop/frontend/index.html`，改了下次 cp 会被覆盖

## 本地服务说明

| 服务 | 端口 | 职责 | 脚本 |
|------|------|------|------|
| ASR 主服务 | 8765 | 语音识别 / edge-tts / 字幕 | `local_asr_server/main.py` |
| IndexTTS2 | 8766 | 声音克隆（异步任务） | `local_asr_server/indextts_server.py` |
| HeyGem V2 | 7861 | 数字人视频生成 | `desktop_client/heygem_server_v2.py` |

**运营者电脑 venv 路径：**
```
F:\qingyuAI\python-modules\voiceV2Module\venv\python.exe
F:\qingyuAI\python-modules\hdModule\venv\python.exe
```

## frp 穿透配置（云端服务专用）

```
asr.yyagent.top    → 127.0.0.1:8765
heygem.yyagent.top → 127.0.0.1:7861
```

后台配置：
- `asr_url` = `http://asr.yyagent.top`
- `video_url` = `http://heygem.yyagent.top`

> ⚠️ 填 `http://` 不填 `https://`，frp 是 HTTP 穿透
