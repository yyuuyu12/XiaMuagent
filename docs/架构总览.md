# 夏木口播视频生成器 · 架构总览

> 更新时间：2026-05-14
> 共三个产品形态，边界清晰，不能混用。

---

## 三个产品形态

| | 手机版 H5 | 网页桌面版 | 独立打包版 |
|---|---|---|---|
| **用户** | 手机浏览器用户 | 电脑浏览器用户 | 购买整合包的买家 |
| **入口** | `https://www.yyagent.top` | `https://www.yyagent.top/desktop` | `夏木桌面版.exe` |
| **前端文件** | `backend/public/index.html` | `backend/public/desktop.html` | `XiaMuDesktop/frontend/index.html` |
| **后端** | Zeabur 云端 Node.js | Zeabur 云端 Node.js | 本地 FastAPI (9101) → 透传 Zeabur |
| **AI 文案** | Zeabur → DeepSeek | Zeabur → DeepSeek | Zeabur → DeepSeek |
| **TTS 语音** | 本地 8766（frp穿透） | 本地 8766（frp穿透） | 本地 8766（直连） |
| **数字人** | 本地 7861（frp穿透） | 本地 7861（frp穿透） | 本地 7861（直连） |
| **ASR** | 本地 8765（frp穿透） | 本地 8765（frp穿透） | 本地 8765（直连） |
| **数据库** | Zeabur MySQL | Zeabur MySQL | Zeabur MySQL（账号共用） |
| **frp 穿透** | ✅ 必须 | ✅ 必须 | ❌ 不需要（本机直连） |

## 本地服务说明

| 服务 | 端口 | 职责 | 脚本 | venv |
|------|------|------|------|------|
| ASR 主服务 | 8765 | 语音识别/edge-tts/字幕/代理入口 | `local_asr_server/main.py` | voiceV2Module |
| IndexTTS2 | 8766 | 声音克隆（异步任务） | `local_asr_server/indextts_server.py` | voiceV2Module |
| HeyGem V2 | 7861 | 数字人视频生成 | `desktop_client/heygem_server_v2.py` | hdModule |

**venv 路径：**
```
F:\qingyuAI\python-modules\voiceV2Module\venv\python.exe
F:\qingyuAI\python-modules\hdModule\venv\python.exe
```

## frp 穿透（手机版/网页桌面版专用）

```
asr.yyagent.top    → 127.0.0.1:8765
heygem.yyagent.top → 127.0.0.1:7861
```

后台配置：
- `asr_url` = `http://asr.yyagent.top`
- `video_url` = `http://heygem.yyagent.top`

> ⚠️ 填 `http://` 不填 `https://`，frp 是 HTTP 穿透
