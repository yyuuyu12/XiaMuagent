## 二、整体架构

```
用户浏览器 ──HTTPS──▶ Zeabur 云后端(Node.js Express + 托管 MySQL)
                          认证 / API / 数据库 / 内存任务队列
                          ↕ HTTP（frp 穿透，填 http:// 不是 https://）
                     本地 Windows(RTX 5070Ti)
                       ├ ASR 主服务 :8765  Whisper/edge-tts/字幕/IndexTTS代理/数字人代理
                       ├ IndexTTS    :8766  声音克隆（经 ASR 的 /tts/indextts/* 代理）
                       └ HeyGem V2   :7861  数字人视频
                     frpc 两条隧道：asr.yyagent.top→8765 · heygem.yyagent.top→7861
```

**本地服务启动**：双击 `local_asr_server/start_services.bat`（内部 ExecutionPolicy Bypass 跑 startup.ps1）。验证 `http://asr.yyagent.top/health` 返回 `{"status":"ok"}`。已关闭开机自启，需手动起。

## 五、核心机制

### 异步任务（避免 Zeabur 网关超时返 HTML 504）
所有"长 AI 调用"都走 taskRunner 异步 + 前端 3s 轮询 /api/tasks/:id。task type：
`clone_video` `profile_analyze` `single_video_analyze` `novel_chapter`（写正文）`novel_gen`（大纲/细纲/设定卡bootstrap/AI识别角色/对话改大纲设定人物 revise_*）`original_analyze`（学习拆解）`original_write`（融合写入 Skill）。

### Skill 体系（原创工坊，五层）
1. **规则**（cw_skills.rules）按创作流程节点分组，**阶段路由**只注入当前阶段相关分组
2. **题材包** 项目挂载，写什么内容
3. **金句库** 跨题材语感样本，写剧本时混搭注入"只学劲不抄内容"
4. **范例库** 定稿成品 show>tell
5. **学习闭环**：对话反馈→待确认池→采纳；定稿 diff 学习；USED 回执计数+效能分休眠；月度反思；学习中心拆解(逐句标注)→流程化经验→融合写入
- 模型：GPT-5.5（管理后台 ai_provider/model 配置；可给创作/小说单配 ai_model_creation/ai_model_novel）

### AI 写小说核心（联动）
- **写章三处注入**：最简记忆包（裁剪本章相关角色+关系+组织）+ 范例 + 金句 + 写作戒律
- **定稿回写**：AI 提取本章新角色/状态/关系变化，自动登记
- **创作搭档统一对话**：选哪个面板（大纲/设定/人物/章节）就改谁
- **章节 2000-3000 字**，同剧情拆更多章

### 视觉
desktop.html 末尾"液态玻璃风覆盖层"：半透明毛玻璃卡片+柔光背景+橙色点睛，纯 CSS 不动结构。
