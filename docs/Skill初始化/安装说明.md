# Skill 初始化 · 安装说明

三份文档，5 分钟装完。装完后你的 Skill 体系 = 主 Skill（通用总纲，永远生效）+ 题材包（按项目挂载）+ 禁区（硬约束）。

## 第 1 步：替换主 Skill（2 分钟）

1. 桌面版 → 我的 Skill → 主 Skill → 编辑
2. **先把现有内容全选复制，存到本地备个份**（系统也有历史记录可还原，双保险）
3. 清空，粘贴 `主Skill-口播创作总纲.md` 的全部内容 → 保存

> 为什么替换而不是追加：你现有 42 条里通用的部分已经吸收进总纲并按统一句式重写了；AI 工具专属的部分拆去了题材包。追加会大量重复，重复规则会稀释 AI 注意力。

## 第 2 步：建第一个题材包（1 分钟）

1. 我的 Skill → 新建题材包
2. 名称填：`AI工具与超级个体`
3. 内容粘贴 `题材包-AI工具与超级个体.md` 的全部内容 → 保存
4. 打开你正在做的项目 → 项目简介 → 题材包下拉选它 → 挂载

以后开新赛道（比如二手奢侈品），复制 `题材包-空白模板.md` 新建一个包，先去学习中心拆 3-4 条该赛道爆款再填，10 分钟成型。

## 第 3 步：填禁区词（1 分钟）

禁区是硬约束——critic 质检查到直接打回重写，比普通规则强得多。建议初始清单（按需增删）：

```
家人们、宝子、姐妹们、绝绝子、yyds、今天来分享、大家好我是、
首先、其次、综上所述、总而言之、赋能、抓手、闭环、颗粒度、
不容错过、干货满满、记得点赞关注、我们下期再见
```

在手机版 H5 → 原创工坊 → 我的 Skill → 禁区 里添加（桌面版禁区编辑后续补）。

## 装完之后系统怎么运转

| 层 | 内容 | 何时生效 |
|---|---|---|
| 主 Skill | 身份、选题、钩子、节奏、语言（通用） | 每次生成全量注入 |
| 题材包 | 该赛道的人群/钩子公式/黑话/禁忌 | 挂载的项目内注入，优先级高于主 Skill |
| 禁区 | 词语黑名单 | critic 硬校验，违规自动重写 |
| 范例库 | 你的定稿成品 | 写剧本时自动模仿文风 |
| 自动学习 | 对话反馈/定稿对比提炼的新规则 | 进待确认池，你采纳后生效 |

## 维护节奏

- **每周**：首页待确认池逐条采纳/忽略（只采纳"下个项目还成立"的）
- **每周**：我的 Skill → 效果数据 看一眼，"从未被用"的规则改写或删
- **每月**：月度反思自动送修订提案；顺手点一次"整理自动学习记录"
- **判断标准**：你自己读不懂的规则，AI 更读不懂——删

## 写新规则的句式标准

```
写…（场景：题材类型/创作环节）时，…（具体怎么做），而不是…（怎么做不对）
```

写不出"而不是"的规则，说明还没想清楚，先放着别入库。
