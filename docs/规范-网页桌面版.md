# 网页桌面版 · 开发规范

---

## 定位

- **用户**：用运营者自己电脑浏览器访问，宽屏体验
- **入口**：`https://www.yyagent.top/desktop`
- **设计**：宽屏优先，viewport 1280，双栏布局

---

## 文件边界（只改这里）

| 要改什么 | 改哪个文件 | 禁止改哪里 |
|---|---|---|
| 页面 UI / 交互 | `backend/public/desktop.html` | 不要改 index.html |
| API 接口 | `backend/routes/对应文件.js` | （和手机版共用） |
| 数据库结构 | `backend/initDb.js` | |

> ⚠️ desktop.html 改完后需同步到独立打包版：
> `cp backend/public/desktop.html XiaMuDesktop/frontend/index.html`

---

## 架构

```
电脑浏览器（宽屏）
    ↓ HTTPS
Zeabur 云端 (yyagent.top/desktop)
    ├── 静态：desktop.html
    └── API：/api/*（与手机版共用同一套）
         ├── AI文案/改写  → DeepSeek
         ├── TTS语音      → 代理到 asr.yyagent.top:8765 (frp)
         ├── 数字人视频   → 代理到 heygem.yyagent.top:7861 (frp)
         └── ASR识别      → 代理到 asr.yyagent.top:8765 (frp)
```

---

## API 地址规则

```js
const API_BASE = `${location.origin}/api`;  // 自动用当前域名
```

与手机版完全一致，不需要改。

---

## 本地服务依赖

与手机版完全相同，都通过 **frp 穿透**：

| 功能 | 依赖端口 | frp 域名 |
|---|---|---|
| 抖音文案提取 | 8765 | asr.yyagent.top |
| 语音合成 | 8765/8766 | asr.yyagent.top |
| 数字人视频 | 7861 | heygem.yyagent.top |

---

## 和手机版的区别

| 项目 | 手机版 | 网页桌面版 |
|---|---|---|
| 文件 | index.html | desktop.html |
| viewport | 480px | 1280px |
| 布局 | 单栏 | 双栏/多栏 |
| 入口 URL | `/` | `/desktop` |
| API | 完全一样 | 完全一样 |
| 本地服务 | 完全一样 | 完全一样 |

---

## 同步规则

**desktop.html 改完后必须同步到独立打包版：**

```bash
cp C:\AIClaudecode\backend\public\desktop.html \
   F:\Projects\XiaMuDesktop\frontend\index.html
```

然后重新打包 exe（见独立打包版规范）。

---

## 部署流程

```bash
git add backend/public/desktop.html
git commit -m "desktop: 说明"
git push   # Zeabur 自动部署
```

---

## 不要做的事

- ❌ 不要把桌面版功能写进 index.html（手机版不需要宽屏逻辑）
- ❌ 不要在 desktop.html 里直连 127.0.0.1 本地服务（会 HTTPS Mixed Content 报错）
- ❌ 不要忘记同步到独立打包版的 frontend/index.html
