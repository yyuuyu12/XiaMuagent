# 手机版 H5 · 开发规范

---

## 定位

- **用户**：手机浏览器访问的普通用户
- **入口**：`https://www.yyagent.top`
- **设计**：移动端优先，max-width 480px

---

## 文件边界（只改这里）

| 要改什么 | 改哪个文件 | 禁止改哪里 |
|---|---|---|
| 页面 UI / 交互 | `backend/public/index.html` | 不要改 desktop.html |
| API 接口 | `backend/routes/对应文件.js` | |
| 数据库结构 | `backend/initDb.js` | |
| 管理后台 | `backend/public/admin.html` | |

> ⚠️ `index.html` 是单文件，所有 CSS/JS 内联，不要拆分

---

## 架构

```
手机浏览器
    ↓ HTTPS
Zeabur 云端 (yyagent.top)
    ├── 静态：index.html
    └── API：/api/*
         ├── AI文案/改写  → DeepSeek
         ├── TTS语音      → 代理到 asr.yyagent.top:8765 (frp)
         ├── 数字人视频   → 代理到 heygem.yyagent.top:7861 (frp)
         └── ASR识别      → 代理到 asr.yyagent.top:8765 (frp)
```

---

## API 地址规则

```js
const API_BASE = `${location.origin}/api`;  // 自动用当前域名
```

不要硬编码 IP，不要写 `106.14.151.37`。

---

## 本地服务依赖

手机版需要本地服务通过 **frp 穿透**才能用：

| 功能 | 依赖 | frp 域名 |
|---|---|---|
| 抖音文案提取 | ASR 8765 | asr.yyagent.top |
| 语音合成（edge-tts） | ASR 8765 | asr.yyagent.top |
| 声音克隆（IndexTTS） | ASR 8765 → IndexTTS 8766 | asr.yyagent.top |
| 数字人视频 | HeyGem 7861 | heygem.yyagent.top |

> 本地服务挂掉或 frpc 断开，对应功能报错

---

## 已知边界问题

| 问题 | 原因 | 处理方式 |
|---|---|---|
| 浏览器无法直接 fetch OSS URL（CORS） | OSS 需配置跨域 | OSS Bucket CORS 添加 yyagent.top |
| TTS 音频生成后 session 恢复音频丢失 | 旧 session 无 base64 | 生成时同时返回 audio + audio_url |
| 提取文案超时 | Whisper 模型加载慢 | 前端超时设 300s，提示用户等待 |

## 不要做的事

- ❌ 不要在 index.html 里引用外部 JS 文件（破坏单文件结构）
- ❌ 不要硬编码本地 IP（127.0.0.1 / 106.14.151.37）
- ❌ 不要在 index.html 里写桌面端专属逻辑（viewport 1280 等）
- ❌ 不要改 desktop.html（那是网页桌面版的）
