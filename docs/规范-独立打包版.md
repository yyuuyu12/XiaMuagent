# 独立打包版（XiaMuDesktop exe）· 开发规范

---

## 定位

- **用户**：购买整合包的买家，自己有 GPU 的电脑
- **入口**：双击 `夏木桌面版.exe`
- **特点**：本机 AI 服务直连（无需 frp），账号登录走 Zeabur 云端

---

## 项目路径

```
F:\Projects\XiaMuDesktop\
├── 夏木桌面版.exe              ← 打包后的 dist 里
├── 一键启动AI服务.bat          ← 买家先运行
├── 整合包目录说明.txt
│
├── desktop_shell/
│   └── main.py                ← pywebview 壳（Edge WebView2）
│
├── backend_local/             ← 本地 FastAPI 后端（端口 9101）
│   ├── main.py                ← ★ 服务入口（代理转发）
│   ├── routes/                ← 本地路由
│   └── database.py
│
├── frontend/
│   └── index.html             ← ★ 前端（从 desktop.html 同步过来）
│
├── XiaMuDesktop.spec          ← PyInstaller 打包配置
└── dist/XiaMuDesktop/         ← 打包输出
```

---

## 架构

```
夏木桌面版.exe（pywebview + Edge WebView2）
    ↓ 启动
本地 FastAPI 后端（127.0.0.1:9101）
    ├── 静态文件：frontend/index.html
    ├── /api/proxy/asr/*     → 127.0.0.1:8765（直连）
    ├── /api/proxy/tts/*     → 127.0.0.1:8766（直连）
    ├── /api/proxy/heygem/*  → 127.0.0.1:7861（直连）
    └── /api/*（其余）        → Zeabur 云端透传（auth/tasks/AI文案等）

本地 AI 服务（买家电脑自行启动）
    ├── ASR/Whisper    :8765
    ├── IndexTTS2      :8766
    └── HeyGem V2     :7861
```

## 文件边界

| 要改什么 | 改哪个文件 | 禁止改哪里 |
|---|---|---|
| 前端 UI | `backend/public/desktop.html` → 同步到 `frontend/index.html` | 不要直接改 frontend/ |
| 本地后端路由 | `XiaMuDesktop/backend_local/main.py` | |
| 打包配置 | `XiaMuDesktop/XiaMuDesktop.spec` | |
| 服务脚本（买家用） | `ai_services/` 下的 py 文件 | |
| pywebview 壳 | `desktop_shell/main.py` | 轻易不要动 |

> ⚠️ 前端唯一来源是 desktop.html，不要直接改 frontend/index.html

## 本地服务端口（买家电脑）

| 服务 | 端口 | 脚本 | 说明 |
|---|---|---|---|
| ASR/Whisper | 8765 | `ai_services/main.py` | 语音识别 |
| IndexTTS2 | 8766 | `ai_services/indextts_server.py` | 声音克隆 |
| HeyGem V2 | 7861 | `ai_services/heygem_server_v2.py` | 数字人视频 |

> ❌ 不用 frp，买家本机直连

## 与手机版/网页桌面版的关键区别

| 项目 | 手机版/网页桌面版 | 独立打包版 |
|---|---|---|
| TTS/ASR 地址 | `http://asr.yyagent.top`（frp） | `http://127.0.0.1:8765`（直连） |
| 数字人地址 | `http://heygem.yyagent.top`（frp） | `http://127.0.0.1:7861`（直连） |
| frp | ✅ 必须跑 | ❌ 不需要 |
| 后端 | Zeabur Node.js | 本地 FastAPI 9101 |
| AI 文案 | Zeabur → DeepSeek | Zeabur → DeepSeek（透传） |
| 账号/数据库 | Zeabur MySQL | Zeabur MySQL（共用） |

## 路径规范（买家整合包）

服务脚本支持三级路径解析，**不要在脚本里硬编码路径**：

```python
# indextts_server.py / heygem_server_v2.py 的路径解析顺序：
# 1. 环境变量 VOICE_MODULE_DIR / HEYGEM_DIR（bat 脚本注入）
# 2. 脚本同级目录下的 voiceV2Module / hdModule（整合包相对路径）
# 3. 硬编码兜底（运营者自用）
```

`一键启动AI服务.bat` 会自动注入环境变量：
```bat
set VOICE_MODULE_DIR=%AI_DIR%\voiceV2Module
set HEYGEM_DIR=%AI_DIR%\hdModule
```

## 整合包目录结构（买家收到的）

```
夏木整合包/
├── 夏木桌面版.exe
├── _internal/                  ← exe 依赖，不要删
├── 一键启动AI服务.bat
├── 整合包目录说明.txt
└── ai_services/
    ├── voiceV2Module/          ← ~22GB（含 Whisper + IndexTTS 模型）
    │   └── venv/Scripts/python.exe
    ├── hdModule/               ← ~10GB（含 HeyGem 模型）
    │   └── venv/Scripts/python.exe
    ├── main.py                 ← ASR 服务（从 local_asr_server/ 复制）
    ├── indextts_server.py      ← 语音克隆（从 local_asr_server/ 复制）
    └── heygem_server_v2.py     ← 数字人（从 desktop_client/ 复制）
```

## 打包流程

```bash
# 1. 同步最新前端
cp backend/public/desktop.html XiaMuDesktop/frontend/index.html

# 2. 打包 exe
cd F:\Projects\XiaMuDesktop
pyinstaller XiaMuDesktop.spec --noconfirm

# 3. 输出在
# F:\Projects\XiaMuDesktop\dist\XiaMuDesktop\
```

**打包环境要求：**
- Python 3.10（x64）
- pywebview、pyinstaller 已安装
- Edge WebView2 Runtime（Windows 10/11 已内置）

## 不要做的事

- ❌ 不要直接改 `frontend/index.html`（改了下次同步会被覆盖）
- ❌ 不要在服务脚本里硬编码路径（买家路径不同）
- ❌ 不要把 frp 相关配置放进整合包（买家不需要穿透）
- ❌ 不要把 OSS/数据库密钥硬编码进脚本（走 Zeabur 配置）
- ❌ 不要在 desktop_shell/main.py 里改后端端口（牵连打包配置）
